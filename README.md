## Instrucciones de uso
1. Abre la **consola / terminal**.
2. Ve a la carpeta del proyecto:
   ```bash
   cd /ruta

3. Ejecuta el script de exportación a HTML:
     ```bash
     python export_html.py

4. Abre el archivo index.html en un navegador (doble clic o arrastrando el archivo).
